# Multi-Agent Contracts & Module Interfaces - EVOCURE

Per Sections 1.2 and 28.3, each specialized agent executed on the Flash model has strict module boundaries, typed inputs/outputs (`simulation/core/contracts.py`), epistemic constraints, and verifiable deliverables.

| Agent Role | Target Directories | Inputs (Contracts) | Verifiable Outputs | Epistemic & Scope Boundaries | Acceptance Criteria |
|---|---|---|---|---|---|
| **Chemistry Agent** | `simulation/chemistry/`, `docs/agents/chemistry_report.md` | SMILES, MOL/SDF, formulas, compound pairs | Validated `CompoundRecord`, RDKit descriptors, 2D SVG, Murcko scaffolds, balanced reactions | Never claims clinical efficacy; rejects invalid valences in Mode B | 100% RDKit-sanitized structures; atomic & charge conservation verified |
| **Physics Agent** | `simulation/physics/`, `docs/agents/physics_report.md` | `EnvironmentConfig`, `list[SpatialEntity]`, `dt`, `rng` | $O(N)$ Spatial Hash motion/collisions, non-negative PDE fields, barrier reflection/transmission | No biological intentionality assigned to simple molecules | $C(\mathbf{x},t) \ge 0$; closed-box mass/energy conservation |
| **Evolution Agent** | `simulation/evolution/`, `docs/agents/evolution_report.md` | Entities/compounds, objective vectors, `GenealogyTracker` | Emergent Darwinian dynamics (Mode A), RDKit mutation + NSGA-II (Mode B), lineage DAG | Never inflates fitness artificially by generation; strict Mode A/B wall | Selection, drift, extinction, and lineage integrity tested |
| **Cancer Biology Agent** | `simulation/biology/`, `docs/agents/biology_report.md` | `DiseaseModule`, `CompoundRecord`, pharmacology profile | 2D PDAC microenvironment (subclones, CAFs, vessels, hypoxia, apoptosis), coevolution | Never reduces drug sensitivity to a single isolated mutation | Tumor growth, hypoxia, stromal barrier, and resistance selection verified |
| **Pharmacology & Toxicology Agent** | `simulation/pharmacology/`, `simulation/toxicity/`, `simulation/systemic/`, `docs/agents/pharmacology_toxicity_report.md` | `CompoundRecord`, QSAR/AD outputs, tumor state | Applied/free/intracellular exposure, Hill PD, 10-category toxicology with `ScientificValue`, 7-compartment PBPK | Zero human dosing advice; `UNMODELED` without PBPK; `INSUFFICIENT_DATA` out of AD | Every metric carries epistemic tag, uncertainty, and limitations |
| **AI/ML & Data Agent** | `ai/`, `data/`, `scripts/manage_models.py`, `docs/agents/ai_data_report.md` | `CompoundRecord`, simulation state, reference datasets | Calibrated `scikit-learn` QSAR + Tanimoto AD, local Gemma 4 + deterministic fallback, Laya AI triage, ChEMBL/PubChem/GDSC reference sets | No LLM decides cancer cures or modifies parameters silently | 100% offline execution; scaffold-split validation without leakage |
| **Simulation & Persistence Agent** | `simulation/core/engine.py`, `simulation/core/persistence.py`, `simulation/discovery/`, `docs/agents/simulation_report.md` | Experiment config, RNG seed, clock commands | 3 separated clocks, batch/realtime runner, SQLite + checkpoints + JSON/CSV/SDF, `EVOCURE-001` | Deterministic replay for identical seed on host CPU | Exact seed reproducibility; FPS invariance |
| **UI/UX Agent** | `app/`, `frontend/`, `run.py`, `docs/agents/ui_ux_report.md` | REST + WebSocket snapshots from unified engine | `EVOCURE PLAY` (4 cards, 8 missions, glossary, tutorial, Compare Worlds) + `EVOCURE LAB` (10 views) | Zero external CDNs; zero Node.js; seamless PLAY/LAB switch | $\le 3$ clicks to start in PLAY; colorblind + keyboard accessibility |
| **Validation Agent** | `tests/`, `docs/agents/validation_report.md` | All modules, APIs, and `EVOCURE-001` scenarios | 5-level `pytest` suite, performance benchmarks, scientific validation summary | Never marks untested features complete | 100% passing tests across all 5 scientific validation levels |
